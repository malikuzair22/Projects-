# AI Projects & Advanced RAG Techniques

A collection of real-world AI projects and advanced RAG implementations
built with LangChain, LangGraph, Groq, and HuggingFace embeddings.

## 🚀 AI Projects

| Project | Description |
|---|---|
| `legal_ai_assistant.py` | RAG-based assistant for legal document Q&A |
| `agentic_rag_realData.py` | RAG pipeline with autonomous agent decision making |
| `Ai_research_agent.py` | Agent that researches and summarizes topics |
| `youtube_chatbot.py` | Chat with any YouTube video using RAG |
| `multimodel_rag/` | RAG pipeline supporting text and images |
| `Rag_from_scratch.py` | RAG pipeline built from scratch without frameworks |

## 🧠 Advanced RAG Techniques

| Technique | Description |
|---|---|
| Multi-Query RAG | Generates multiple queries for better retrieval |
| Re-Ranking | Re-ranks retrieved chunks for higher relevance |
| HyDE | Hypothetical Document Embeddings for better search |
| Parent Document | Retrieves small chunks, passes large context to LLM |
| Contextual Compression | Compresses retrieved context before passing to LLM |
| Self-RAG | Model decides when and what to retrieve |
| Corrective RAG | Evaluates and corrects retrieved documents |

## 🛠️ Tech Stack

- **LLM:** Groq (llama-3.3-70b-versatile)
- **Embeddings:** HuggingFace
- **Vector Store:** FAISS
- **Frameworks:** LangChain, LangGraph
- **Language:** Python 3.10+

## ⚙️ Setup

```bash
git clone https://github.com/malikuzair22/Projects-.git
cd Projects-
pip install -r requirements.txt
```

Create a `.env` file:

GROQ_API_KEY=your_key_here
HUGGINGFACE_API_KEY=your_key_here
